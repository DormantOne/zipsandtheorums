Exact structured-compute demonstration

Dense compute vs a dyadic GlyphFold-style path

One self-contained browser lab: first compare a very large matrix-vector operation with its exact dense realization; then train two tiny networks on XOR and count the arithmetic needed to reach the same confidence criterion.
Usual: unstructured denseThis: diagonal + permutation + butterfly foldNo libraries · no pretrained weights

What “this” means here

The structured operator is deliberately explicit and reproducible:

W = D₂ · H · P · D₁

H is a normalized Walsh-Hadamard butterfly, P is a fixed permutation, and D₁/D₂ are learned or chosen diagonal scales.

Why the structured net wins here: XOR is exactly represented by the fixed feature (x₁−x₂)² for binary inputs. The compute reduction comes from an inductive bias matched to the task, not from a universal claim that every neural network can be compressed this way.
Counting model. A dense MAC is shown as one multiply plus one accumulation. The structured matrix path counts 2N diagonal multiplies, Nlog₂N butterfly add/subtracts, and N routing moves. FP32 storage includes two diagonal vectors and one uint32 permutation. XOR training counters include full-batch forward pass, analytic backpropagation, gradient accumulation, and parameter updates for the code in this page. Comparisons exclude browser rendering and JavaScript loop overhead.
